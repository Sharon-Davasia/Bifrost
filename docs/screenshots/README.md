# Screenshot placeholders

The README references three screenshots. They are deliberately **not** included: real
captures from your own instance are more useful than mock-ups, and no mock data belongs
in the repository.

| File | Suggested capture |
| --- | --- |
| `pairing.png` | Phone (≈390 × 844, 2× DPR). Open `http://<LAN-IP>:8000/` and show the “Pair this device” card with the six PIN boxes focused. |
| `inbox.png` | Laptop (≈1280 × 800). Inbox with two image thumbnails, one PDF-style file icon and one multi-line note, plus the upload drop zone. |
| `uploading.png` | Phone. Three uploads in progress at different percentages with a fourth row showing “Waiting…”. |

Tips:

- Use the browser's device toolbar for consistent mobile framing.
- Crop out the address bar if it contains a LAN IP you would rather not publish.
- Do not stage the host-only PIN panel in shared screenshots if the host is reachable
  from outside your network (the PIN changes on every restart, but still).
